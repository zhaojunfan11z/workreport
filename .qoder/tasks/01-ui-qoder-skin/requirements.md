# UI 视觉向 Qoder 对齐（皮肤层）

## 目标

插件工具窗口的视觉观感对齐 Qoder 聊天面板：中性灰对话气泡、tab 式会话标签、绿色发送键、更紧凑的圆角与间距。**不改布局结构、不改交互逻辑**。

## 已确认口径（2026-11-16）

| 决策点 | 结论 |
|---|---|
| 改造范围 | 先做视觉皮肤：配色 / 圆角 / 间距 / 气泡 / 标签样式 / 发送键，不动布局 |
| 主题策略 | 跟随 IDE 明暗，深色主题下贴近 Qoder 截图，浅色主题自动换浅色板 |
| 强调色 | 发送键与选中态用 Qoder 绿；链接、焦点环仍用 IDE 蓝 |

## 改造项

1. `UiTheme`：新增 `BUBBLE`（用户气泡中性灰）、`SEND` / `SEND_HOVER`（Qoder 绿）
2. `UiButton`：`SOLID` 支持自定义填充色与 hover 提亮
3. `UiMetrics`：气泡 12→10、卡片 10→8、chip 8→6（更接近 Qoder 的小圆角）
4. `UserMessageView`：用户气泡由"实底强调蓝 + 白字"改为"中性灰底 + 正文色"
5. `SessionTabsBar`：选中态由强调淡底 + 底部 2px 条改为浅灰底 + 加粗正文色（tab 化）
6. `ChatComposer`：发送键改绿色圆角方形（非正圆）
7. `StatusRow`：右侧 meta chip 去底色，改纯灰小字
8. `ChatView`：块间距 12→10，行高更紧凑

## 不做

- ~~输入区布局重排~~（第二阶段已实现：添加上下文入框、模型选择移出）
- 变更文件摘要条（"27 变更文件 · 已应用/撤销全部/保留全部"）
- 工具窗口顶栏的头像/更多菜单
- 工具调用卡片的结构性改版（仅跟随新色板与圆角）

## 验收

- 深色主题下：用户消息为灰底黑字气泡，标签条为 tab 样式，发送键为绿色圆角
- 浅色主题下：整体仍是浅色板，不出现强行深色
- `gradlew classes` / `buildPlugin` 通过，打包可安装
